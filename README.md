# Xiao Bei · 个人主页

全栈开发者个人品牌网站，带有毛玻璃设计、音乐播放器和粒子动画的交互式个人主页。

## ✨ 功能

- **加载动画** — 绿色主题的加载画面，带有流光文字
- **入场序列** — 交错的渐入动画（标题、头像、副标题、格言）
- **音乐播放器** — 基于 HTML5 Audio 的播放器，支持切歌、播放列表、频谱可视化
- **动态主题** — 根据歌曲自动切换视觉主题（theme-b 森林绿 / theme-c 夜空紫）
- **粒子系统** — 漂浮粒子背景，鼠标移动产生排斥效果
- **毛玻璃 UI** — 基于 backdrop-filter 的玻璃态设计
- **响应式布局** — 适配不同屏幕尺寸

## 🛠️ 技术栈

- 纯 HTML + CSS + JavaScript（无框架依赖）
- CSS 自定义属性（变量）实现主题切换
- Web Audio API 实现频谱可视化
- CSS 动画与过渡驱动入场序列
